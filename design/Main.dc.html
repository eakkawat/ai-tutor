Diagnosis

You can set up a location and a character clearly. Gap: Mai's want only shows up in the last line, so Grandma's resistance has nothing to push against.

Learn · 1 min read

State the want early, then block it

A scene works when the audience knows what the character wants before the trouble starts. Once the want is clear, every refusal, delay or trick from the other side reads as tension. [Book A · ch. 3 · p. 41]

The obstacle should be active: a person or force pushing back, not bad luck. Each exchange should shift who has the upper hand. [Book B · ch. 7 · p. 112]

Example

In a heist film, we learn what the crew wants in the first minute, so every locked door and every guard matters.

Your work will be judged on
  1. The want is clear by the end of the first beat.
  2. The obstacle actively opposes the want.
  3. Each exchange shifts who has the upper hand.
  4. The scene ends with the want won, lost, or changed.
