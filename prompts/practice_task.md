Return:
- `title`: a short name for the task.
- `instructions`: what to make, at most 90 words, in second person. Name the project's own characters and places. Say how long or how much (for example "under one page").
- `template`: a list of 3 to 6 short beat labels the learner can fill in. Only when a beat template is on; otherwise an empty list.
- `worked_example`: a short worked example of the skill on a made-up case (not their work). Only when a worked example is on.
- `hint`: one hint that points without giving the answer. Only when a hint is on.
- `steps`: the task split into 3 to 5 short steps. Only when split into steps is on.
- `smaller_scope`: one sentence narrowing the task to a smaller piece. Only when smaller scope is on.
- `constraint`: one extra constraint that makes it harder (for example a rule about what may not be used). Only when a constraint is on.
- `higher_standard`: one sentence raising the bar on how the principles are applied. Only when a higher standard is on.
- `combine`: one sentence that also asks for the skill named in the setup. Only when combining is on.
- `minutes`: how long the task should take, between 15 and 25.

Leave every piece that is not switched on empty. Never add help or difficulty that the setup does not ask for.
